### Selected work

**RASED · راصد** — traffic intelligence and action layer for Amman<br>
Reads one unified picture of the road network and proposes a concrete intervention — signal
retiming, a coordinated green wave, an officer, a variable message sign — rather than only
reporting conditions.<br>
<sub>Lead contributor · team of 5 · TypeScript, Python, PostgreSQL, SUMO</sub>

**VoC-360** — Jordan's national citizen-experience intelligence platform<br>
Carries citizen feedback from intake through an NLP intelligence layer into
business-intelligence dashboards and citizen-facing channels.<br>
<sub>Core contributor · team of 26 · Python, TypeScript, microservices</sub>

**[Options Alpha Agent](https://github.com/nizarhazaymeh/tradingbot)** — an options agent that
trades only when the premium is worth the risk<br>
Built for the Alpaca AI Trading Agents Hackathon. Rather than predicting direction, it asks
whether a specific multi-leg structure is priced better than the risk it carries — a question
with a measurable answer.<br>
<sub>Lead contributor · Python, Alpaca API, MCP, LLM</sub>

**Course Builder & Player** — Moodle 5.x course semantics rebuilt from scratch<br>
A real availability tree, per-user completion feeding back into availability, and import of
genuine Moodle `.mbz` backups — written by understanding the behaviour, not copying the code.<br>
<sub>FastAPI, SQLite, React, TypeScript</sub>
